WEBSITE UNTUK SAYANGKU ❤️

Foto-foto yang kamu kirim sudah dimasukkan ke website.

Cara menjalankan:
1. Ekstrak ZIP ini.
2. Buka folder website_untuk_sayangku_2pages di VS Code.
3. Buka index.html dengan Live Server.

Halaman:
- index.html: surat cinta
- foto-kenangan.html: galeri 5 foto
- momen-spesial.html: galeri 4 foto

Semua foto tersimpan di folder images. Jangan memindahkan atau mengganti nama folder/file foto jika tidak mengubah alamat src di HTML.
